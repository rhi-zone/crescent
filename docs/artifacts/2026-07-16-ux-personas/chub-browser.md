# Persona: Chub.ai browser/discovery user

okay so my friend keeps texting me about this thing, "just try it, it's not like the others," and I finally cave on the train home. pull out my phone, thumb hovering over the app store search bar, type in the name she gave me. there it is, tiny icon, not many reviews yet. download. wait through the progress ring like always feeling a little impatient about it.

open it up. first screen is some kind of login/signup wall, ugh, okay fine, I do the email thing because I don't want to give it my google account for a random app I might delete in ten minutes. verify code, type it in, in.

home screen. it's… empty. no cards. right, of course, it's not chub, it doesn't have my stuff. I'm looking around for an import button because that's the whole reason I'm here — I've got probably forty cards downloaded onto my phone from chub already, PNGs with the character data baked in, some JSONs too. I see a plus icon bottom right, tap it. menu pops up: "new character," "import." there it is. tap import.

file picker opens, native android one, I navigate to downloads folder. scrolling past screenshots and receipts and there — a folder I made called "cards" with all the chub exports in it. pick one, some fantasy tavern-keeper OC I grabbed last week because the art was good and the description promised actual personality instead of just "loves cuddles UwU."

it thinks for a second. progress bar, then a preview screen — shows me the avatar, the name, first message, personality summary pulled out of the PNG metadata. I'm relieved it actually parsed it correctly, I've had apps mangle the exif/png-chunk data before and just show me a blank card. tap "import" to confirm.

back on home screen now there's one card. tap it.

chat opens. it's got the character's greeting already sitting there in the bubble, formatted with the little asterisk actions and everything, exactly like it would look on chub itself, so that's good, no reformatting weirdness. there's a text box at the bottom, keyboard pops up. I type something dumb, "what are you drinking tonight," hit send.

little typing indicator, three dots, and I'm watching it half-expecting a canned response but it actually plays into the tavern-keeper thing, mentions a specific drink, references the first message. okay that's decent. I send a follow-up, poke a little at the personality to see if it breaks character, it doesn't. cool. I check top right for a regenerate/swipe option in case I don't like a reply — there's a little refresh icon under the bubble, tap it once just to see, get a different response. good, that's the feature I actually care about, means I can reroll instead of being stuck with a bad line.

now I want to know if I can get MORE cards without doing the whole download-then-import dance every time, that's the annoying part on other apps. I go looking — is there a browse tab? bottom nav has like four icons, chats, a compass-looking one, plus, profile. tap the compass. it opens onto some kind of discovery feed, cards other people made directly in-app maybe? I'm scrolling, it's not chub's catalog, it's this app's own community, smaller, feels newer. I'm a little disappointed there isn't a "import from chub via link" option, like paste a URL and it just pulls it — I look for that specifically, check if there's a paste-a-link field anywhere near the import button, don't see one, only local file import. mental note, kind of a gap.

I poke the profile tab to see if there's a way to share what I imported — my friend and I always send each other cards. I find the character I imported, tap the three-dot menu on it, options like "delete," "edit," and there — "share." tap it, it kicks out to the normal phone share sheet, so I could send the file to her over messages probably. good enough, that answers the question.

I close the app there, kind of satisfied — the actual chatting felt smooth and it respected the character data instead of flattening it, that's the bar most of these fail. the missing piece is it doesn't talk to chub directly, so I'm still going to be doing the download-then-import shuffle every time I find something new there, which is mildly annoying but not a dealbreaker. gonna text my friend back "yeah it's decent, still have to manually import tho."
