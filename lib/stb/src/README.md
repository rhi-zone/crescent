# stb headers

The stb headers are not committed to this repository.

Download the following files from https://github.com/nothings/stb and place them here:

- `stb_image.h`
- `stb_image_resize2.h`
- `stb_truetype.h`

Then run `luajit lib/stb/build.lua` to compile the vendored binary for your platform.
